# Emanuel Ventura Mendez - CV Web & Backend Profile

Este repositorio contiene el código fuente de mi currículum web interactivo, diseñado con estructuras limpias, semánticas y optimizadas para sistemas de filtrado ATS.

## 🚀 Demo En Vivo
Puedes ver mi CV online aquí: https://emam22.github.io/emanuel-mendez-cv/

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructuración semántica de la información del perfil.
* **CSS3:** Estilos personalizados basados en variables globales (`:root`) con un diseño ejecutivo de una sola columna.

## 🎯 Enfoque Técnico
Este diseño fue estructurado estratégicamente para destacar competencias clave en desarrollo Backend (**Java, colecciones polimórficas**) y gestión de bases de datos relacionales (**MySQL, MER/DER, consultas complejas**).
